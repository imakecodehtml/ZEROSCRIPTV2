ZEROSCRIPT 1.0 — WINDOWS

BUILD AUTOMÁTICO DEL EXE:
1. Subí esta carpeta a un repositorio nuevo de GitHub.
2. Abrí la pestaña Actions y ejecutá "Build ZEROSCRIPT Windows".
3. Al terminar, descargá el artifact ZEROSCRIPT-Windows-EXE.
4. Dentro vas a encontrar ZEROSCRIPT-1.0.0-Portable.exe.

BUILD LOCAL (opcional):
- Instalar Node.js LTS.
- Abrir CMD en esta carpeta.
- Ejecutar: npm install
- Ejecutar: npm run dist

La aplicación importa, lista, guarda y permite localizar archivos .manifest.
No desbloquea juegos, no crea licencias y no evita los controles de Steam.
